# TypeScript & OOP Assignment

# Overview

This assignment focuses on improving my understanding of TypeScript and Object-Oriented Programming concepts. It includes practical problems based on functions, type annotations, optional parameters, union types, interfaces, type narrowing, generics, promises, and classes.

Through this assignment, I practiced writing type-safe and reusable code using TypeScript features. I also learned how different OOP concepts like access modifiers, inheritance, and class design work in TypeScript.

The assignment also includes two technical blog posts where I explained important TypeScript topics with examples and practical use cases.

# Files

- solutions.ts - Contains all the solutions for the programming problems.
- type-vs-interface.md - Explains the differences between Type Alias and Interface in TypeScript.
- generics-and-promise.md - Explains how Generics work and how they are used with Promise<T>.
